# Vergleichsmatrix

Redaktionelle Einschätzung vom 9. November 2026. „Stark“ steht für eine im Vergleich besonders deutlich erkennbare Lösung. „Gut“ bezeichnet einen klaren Ansatz, „gemischt“ eine Stärke mit konkret sichtbarer Einschränkung. Die Performance-Spalte bewertet ausschließlich den in der Chromium-Stichprobe erkennbaren Medien- und DOM-Aufwand. Sie enthält keine Lighthouse-, Felddaten- oder Umsatzwertung. Bei allen sechs Seiten ergab die Messung bei 390 Pixeln eine Dokumentbreite von 390 Pixeln.
