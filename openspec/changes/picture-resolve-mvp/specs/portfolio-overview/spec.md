## Purpose

Let potential clients discover verified Picture Resolve productions and reach each available project.

## ADDED Requirements

### Requirement: Authentic, navigable project collection

The overview SHALL render sourced project titles, appropriate format labels and accessible links to existing project pages.

#### Scenario: Choosing a project

- **WHEN** a visitor activates a listed project
- **THEN** the matching detail page opens and identifies the same production.

#### Scenario: Viewing on a smaller display

- **WHEN** a visitor uses touch or keyboard at phone width
- **THEN** the work fits the viewport and each title is visible without hover.

#### Scenario: Unavailable preview

- **WHEN** a project has no playable or displayable preview
- **THEN** its text identity and valid project link remain accessible.
