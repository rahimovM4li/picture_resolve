## Purpose

Give Picture Resolve a recognisable editorial language grounded in its existing handwritten identity.

## ADDED Requirements

### Requirement: Identity, hierarchy and legibility

The showroom SHALL use the recovered mark where available, photographic compositions, a restrained red accent, consistent spacing and a legible German type hierarchy.

#### Scenario: Reviewing the identity

- **WHEN** a visitor enters through any major page
- **THEN** the mark, palette and type hierarchy identify the studio across navigation, body and footer.

#### Scenario: Reading a narrow layout

- **WHEN** a visitor views the page at 390 CSS pixels
- **THEN** the headline wraps intentionally and text remains readable over the chosen film crop.

#### Scenario: Asset failure

- **WHEN** a wordmark or decorative photograph fails to load
- **THEN** the home link retains an accessible studio name and page headings remain readable.
